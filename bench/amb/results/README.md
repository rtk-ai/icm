# Benchmark results: data licenses

The JSON files here are per-question results of ICM runs. Besides ICM's own output, each record quotes the benchmark's question and its reference (gold) answer. That quoted material belongs to the datasets below and stays under their licenses, not under ICM's Apache-2.0 (issue #514).

| Files | Dataset | License |
| --- | --- | --- |
| `locomo10-*` | LoCoMo, Maharana et al., "Evaluating Very Long-Term Conversational Memory of LLM Agents" (ACL 2024), https://github.com/snap-research/locomo | CC BY-NC 4.0: https://creativecommons.org/licenses/by-nc/4.0/ |
| `longmemeval-*` | LongMemEval, Wu et al., "Benchmarking Chat Assistants on Long-Term Interactive Memory" (ICLR 2025), https://github.com/xiaowu0162/LongMemEval | MIT, Copyright (c) 2024 Di Wu |
| `personamem32k-*` | PersonaMem, "Know Me, Respond to Me: Benchmarking LLMs for Dynamic User Profiling and Personalized Responses at Scale" (COLM 2025), https://github.com/bowen-upenn/PersonaMem | MIT, Copyright (c) 2024 bowen-upenn |

LoCoMo's license allows non-commercial use only: the LoCoMo excerpts in these files may not be used commercially. The `.md` files hold aggregate figures only.
